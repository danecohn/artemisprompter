Vigil Prompter 0.1.2, a product of VigilTech (vigiltech.org).

Local-first Markdown application for Windows Intel/ARM, macOS Intel/Apple silicon, and Linux Intel/ARM. Each native package passes file read/write and rendering checks before publication; Prompter also compiles and exports a real connected prompt bundle. SHA-256 files accompany the installers.

Mac builds are ad-hoc signed and strictly verified, including the application mounted from the downloaded disk image. They are not Apple-notarized. Windows builds are unsigned. No account, cloud sync or MCP connection is included in this desktop release.

GPL-3.0-only. Third-party notices retained. This is independent original software, not a fork or rebrand of the proprietary Obsidian application.

Linked local raster images are included in generated prompt bundles, with safe rewritten paths. External images are not downloaded.
